# Herdr 配置：把界面与会话分开迁移

## 目录职责

应用读取 `$HERDR_APP_HOME`，未设置时为 `~/.config/herdr-app`。

| 文件/目录 | 职责 |
| --- | --- |
| `settings.json` | zoom=1.2，终端字号16，终端/界面字体，声音开关 |
| `keys.json` | global 与 terminal 两组原生键位 |
| `shared.json` | 选择 cycle-main，启用 Files/Changes；不是工作区数据库 |
| `layouts/cycle-main.json` | 克隆自 main 0.1.10 的个人布局 |
| `mods/cycle-tabs/main.js` | Pane 循环、标签栏与按工作区记忆的面板 |
| `mods/*/mod.json` | 模块标题、展示位置等元信息 |
| `frame/` | 欢迎页、设置、命令面板等框架界面 |
| `installed.json` | 上游文件指纹；不要手动维护或当作偏好设置 |
| `themes/`、`icons/` | 主题与图标等资源 |

`cycle-tabs` 引用其他模块的图标、菜单和面板。因此不仅带走这一份 JS，还保留整套本机运行资源。`gpui-kit`、`gpui-base`、`herdr` 是桌面端提供的模块，**不是需要 npm install 的包**。本包不含编译后的应用。

## 调整方法

修改后先保留一份配置备份；不确定热加载边界时退出并重开应用。

- 字体、字号与缩放：编辑 `settings.json`。字号还受 zoom 影响；16×1.2 的运行字号是19.2。缺字先核对字体确已安装，不要拷字体缓存。
- 快捷键：编辑 `keys.json`，如 `ctrl-tab` → `cycle-tabs.next`。跨 Workspace 循环的代码入口是 `cyclePane(direction)`，不是内置 `tab.next`。
- 默认布局：`shared.json` 的 `layout` 必须对应 `layouts/<名称>.json`。`cycle-main` 的 Tab 栏必须引用 `cycle-tabs`，否则自定义命令没有接收者。
- 默认侧面板：`workspace.panels` 控制按钮候选项；工作区是否展开由模块 localStorage 决定。
- 调布局结构：优先克隆到个人名称。Herdr 自带布局/模块由升级机制维护，直接改上游文件可能被移到 `*-edited`；个人克隆不是免维护的跨版本 API 保证。

## 迁移差异记录

保留原始 settings、keys、cycle-main、cycle-tabs 及其依赖资源。`shared.json` 只保留布局、面板、完成欢迎引导三项，移除了旧 Workspace ID 对应的颜色和 Win98 时间戳。未打包 `view.json`、`window.json`、`data/`、`telemetry/`、`layouts/.state/`、更新媒体、生成的类型声明和编辑器 jsconfig。`installed.json` 是公开资源指纹，不含登录态，仍保留供升级识别。

本机没有独立的 `~/.config/herdr-core` 偏好目录可打包。core 运行数据、远端机器、SSH 和 Shell 配置不属于此包。已有 `me/1` 会话也不带走；配套 Hammerspoon 的 Caps+N 需要在新机建立同名上下文。

## 验证与排错

```sh
APP=/Applications/Herdr.app/Contents/MacOS/Herdr
"$APP" --version
hc --version
"$APP" status
"$APP" check "$HOME/.config/herdr-app/mods/cycle-tabs"
```

`check` 用实际 Herdr 模块运行时检查，不等于 Node 的模块解析。自定义安装目录须替换最后一条路径。`status` 里应看到 `layout: cycle-main`，检查 `errors`。创建几个测试 Pane 后正反向循环，检查顺序与边界回绕。

- 界面空白/图标丢失：核对整包是否复制；查看模块检查输出和运行 errors。版本不同先核对模块 API。
- 终端不启动：先确认 core 安装、Shell 和 PATH，配置文件不会安装这些程序。
- Cmd+1/2 不生效：那是 Hammerspoon 提供的全局映射，不是此处缺文件。
- 新电脑没有旧项目/远程服务器：这是预期隐私边界，请自行创建工作区并重新登录。
- 恢复上游默认：`app.reset` 会把当前布局和键位移到旁边并切回默认；恢复本包应退出应用后重新执行安装脚本，先看清备份位置。

第三方界面模块会调用终端、执行命令并访问文件；只安装可信模块。不要将 API 密钥写入待同步的配置。新增资源或修改上游模块时保留其许可和来源说明。
