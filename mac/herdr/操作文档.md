# Herdr 操作：Workspace → Tab → Pane

Workspace 对应一组任务上下文，Tab 归属 Workspace，一个 Tab 可以左右/上下分成多个 Pane。先用工作区隔离项目，再用标签隔离任务，最后用分屏对照终端输出。

## 日常键位

| 快捷键 | 实际行为 |
| --- | --- |
| Cmd+N / Cmd+Shift+T | 新建 Workspace |
| Cmd+T | 当前 Workspace 新建 Tab |
| Cmd+R / F2 | 重命名 Tab |
| Cmd+Shift+R / Shift+F2 | 重命名 Workspace |
| Cmd+D / Cmd+Shift+D | 向右 / 向下分屏 |
| Cmd+W | 关闭当前 Pane，并结束其终端；不是隐藏 |
| Cmd+Shift+W | 关闭 Workspace，影响其终端；注意确认提示 |
| Cmd+Shift+Enter | 聚焦 Pane 与恢复全部分屏之间切换 |
| Cmd+Alt+方向键 | 聚焦相邻 Pane |
| Cmd+Alt+Shift+方向键 | 与相邻 Pane 交换 |
| Ctrl+Tab / Ctrl+Shift+Tab | 自定义全局 Pane 顺序循环，向后 / 向前 |
| Cmd+Shift+] / [ | 下一个 / 上一个 Tab |
| Cmd+Alt+] / [ | 下一个 / 上一个 Workspace |
| Ctrl+1…9 | 第 1…9 个 Workspace |
| Cmd+3…9 | 当前 Workspace 第 3…9 个 Tab |
| Cmd+P | Picker |
| Cmd+Shift+P | 命令面板 |
| Cmd+, | 设置 |
| Cmd+B | 隐藏/显示左侧栏 |
| Cmd+Shift+L | 循环布局 |
| Cmd+/ 或 Cmd+Shift+/ | 帮助键位 |
| Cmd+= / Cmd+- / Cmd+0 | 放大 / 缩小 / 重置缩放 |

**Ctrl+Tab 不是仅切标签。** `cycle-tabs` 按 Workspace 顺序、各自 Tab 顺序、Tab 内 Pane 列表顺序遍历，末尾回到开头；反向同理。焦点不在列表中时，向后选第一项，向前选最后一项。其他布局没有挂载本模块时，不保证这个自定义命令生效。

本包故意没有绑定 Cmd+1/2。若同时使用配套 Hammerspoon，其全局 Cmd+1/2 会发送 Ctrl+Shift+Tab / Ctrl+Tab，才会得到同样循环。单独安装 Herdr 请直接用 Ctrl 组合键。

## 标签栏与侧面板

- 单击标签切换，双击重命名；在标签间按住拖放可改变顺序，右键打开菜单。
- 标签栏 `+` 打开新建菜单。滚轮垂直方向触发前后标签切换。
- 右上 `Files` / `Changes` 显示文件树/修改面板；再次点击当前按钮关闭。
- 面板开闭与类型按 Workspace 记忆，存于该模块 localStorage，不随本包迁移。

## 终端编辑快捷键

| 快捷键 | 行为 |
| --- | --- |
| Cmd+C / Cmd+V | 复制选择 / 粘贴 |
| Ctrl+V | `terminal.paste_image`；具体图片/平台行为由应用决定 |
| Alt+← / → | 向终端发送 ESC-b / ESC-f，Shell 通常按单词移动 |
| Alt+Backspace | 发送 Ctrl+W |
| Cmd+← / → | 发送 Ctrl+A / Ctrl+E |
| Cmd+Backspace | 发送 Ctrl+U |

这些发送序列的解释取决于当前 Shell/TUI；不能假设每个终端程序都按文本编辑语义处理。

## 一个完整流程

新建 Workspace，重命名为项目名；在 Tab 里运行编辑器，用 Cmd+D 分出终端启动项目。Ctrl+Tab 在各项目所有 Pane 间循环；需要只切当前项目标签时用 Cmd+Shift+[ / ]。结束任务前确认进程用途，再关闭 Pane。关闭桌面窗口与结束 core 终端不是同一件事；`hc` 维护的终端可独立存活。

需要诊断时运行：
```sh
/Applications/Herdr.app/Contents/MacOS/Herdr status
/Applications/Herdr.app/Contents/MacOS/Herdr ls
```
应用若不在 `/Applications`，替换实际路径。不要把输出里的项目路径与终端信息直接公开。
