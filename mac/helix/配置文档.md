# Helix 配置：偏好与语言工具分层

| 文件 | 职责 |
| --- | --- |
| `config/config.toml` | 主题、界面、搜索、剪贴板、三种模式的键位 |
| `config/languages.toml` | 语言服务、formatter 与安装期路径模板 |
| `install.sh` | 用 mise 查路径，先检查后备份，生成可加载配置 |

源机器有一个很大的用户 `runtime/grammars/sources/` 下载源码树，未当作配置复制。此包使用 Helix 安装发行版配套的 runtime（主题、查询、语法）；不要混用别的版本 runtime，也不要设置指向旧用户名目录的 `HELIX_RUNTIME`。如有自定义 runtime，需另行评估迁移，本包不宣称收录下载源码树里的所有第三方语法。

## 语言工具对应表

| 语言 | LSP | formatter |
| --- | --- | --- |
| TS/TSX/JS/JSX | typescript-language-server + TypeScript SDK | Prettier |
| Vue | @vue/language-server 2.1.10 独立模式 | Prettier |
| Svelte / Astro | svelteserver / astro-ls | Prettier + 各自插件 |
| HTML/CSS/SCSS/JSON/JSONC | vscode-langservers-extracted | Prettier |
| YAML/Compose | yaml-language-server | Prettier |
| Markdown | marksman | Prettier |
| Bash | bash-language-server | shfmt |
| Python | Pyright + Ruff（Ruff 不提供 hover） | Ruff |
| Go/mod/work/template | gopls | Go 源码用 gofmt |
| Lua | lua-language-server | StyLua |
| TOML | Taplo | Taplo；保存不自动格式化 |
| C/C++ | xcrun clangd | xcrun clang-format |
| Swift | xcrun sourcekit-lsp | xcrun swift-format |
| Dockerfile | docker-langserver | 未另设 formatter |
| JSON5/GraphQL | 未另加专属语义服务 | Prettier |
| XML / SQL | 未另加专属语义服务 | xmllint / sql-formatter |

没有安装某种语言工具不会使所有纯文本编辑失效，但对应诊断/跳转/格式化会不可用。Shell 服务以 Bash 为主，不保证 zsh 专用语法；SQL formatter 未显式传项目配置参数。

## 为什么安装时渲染

mise 把 npm 工具隔离安装。TypeScript server 和 Astro/Vue 的 tsdk，以及两个 Prettier 插件必须给真实模块路径；原配置中的 `/Users/.../.local/share/mise/...` 不能照搬。模板用 `@@TYPESCRIPT_ROOT@@`、`@@SVELTE_PLUGIN_ROOT@@`、`@@ASTRO_PLUGIN_ROOT@@`，安装脚本从 `mise where` 取位置并按 TOML 字符串转义。

升级 SDK 或插件、移动 mise 数据目录后必须重新执行本目录安装脚本；路径渲染只在安装时发生。修改模板要先保存迁移源再安装，不能只改生成文件后又期望下次安装保留。目标上的普通偏好可直接编辑；主配置用 `:config-reload`，语言定义和 PATH 变动后重启 hx 更稳妥。

## 迁移差异与安全

保留原主题、模式和键位；只清理失效注释，绝对 SDK/插件路径改成安装期模板，Xcode-beta 安装路径改为 xcrun 跟随当前选中工具链。没有附账户、项目、Shell 历史、全局 mise 配置或所有 grammar 源码。formatter/LSP 是在本机执行的外部程序，项目配置会影响它们，进入不可信项目之前应审查其配置。

## 排查顺序

1. `hx --version`，确保是兼容配置的版本。
2. `hx --health typescript`（或 python/vue 等），检查命令和 runtime。
3. `mise where npm:typescript@6.0.3` 与目标 languages.toml 对照，不应剩 `@@...@@`。
4. `command -v prettier pyright-langserver taplo`，确认启动 hx 的终端确实继承 mise PATH。
5. C/Swift 用 `xcrun --find clangd`、`xcrun --find sourcekit-lsp` 检查所选工具链；单装 CLT 不保证含全部 Swift 格式化工具。
