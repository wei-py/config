# Helix 操作：先选择，再动作

从终端执行 `hx .` 浏览文件，或 `hx 文件路径` 打开文件。普通模式负责移动与选择，`i` 进入插入，`v` 进入选择模式，Escape 返回普通模式。Helix 的核心是“选中文本后操作”，不是 Vim 的完整按键复刻。

## 本机自定义键位

空格分隔表示依次按键，不是同时按；大写键需要 Shift。

| 模式 | 键 | 行为 |
| --- | --- | --- |
| 普通/选择 | H / L | 物理行首 / 行尾（H 不是首个非空白字符） |
| 普通 | G | 文件末尾 |
| 普通 | q q | 手动格式化当前文档；覆盖了 q 的原录制入口 |
| 普通 | r r | 单词标签跳转，与默认 g w 同一命令；覆盖 r 的原入口 |
| 普通 | [ e / ] e | 上一个 / 下一个诊断 |
| 插入/选择 | j k | 回普通模式，会把 j 当成按键序列前缀 |
| 插入 | Alt+x | 回普通模式 |

## 常用内置操作

| 键/命令 | 用法 |
| --- | --- |
| h j k l | 左下上右移动 |
| w / b / e | 词向前 / 向后 / 词尾 |
| x | 选中整行，连续按扩展 |
| d / c | 删除选区 / 删除后进入插入 |
| y / p | 复制选区 / 在后面粘贴；本配置默认使用系统剪贴板 |
| u / U | 撤销 / 重做 |
| /，n / N | 搜索、下一个 / 上一个结果 |
| g g / g d | 文件开头 / LSP 定义跳转 |
| Space f / Space b | 文件选择器 / 缓冲区选择器 |
| Space a | LSP 代码操作 |
| :w / :q / :wq | 保存 / 关闭 / 保存并关闭 |
| :config-open / :config-reload | 打开主配置 / 重载可重载的配置 |
| :format | 与 q q 相同的格式化命令 |

鼠标已关闭，请用键盘操作。相对行号用于移动计数；scrolloff=50 会尽量让光标远离上下边缘，在矮终端中可能感觉总在居中。搜索启用 smart-case 与循环：含大写时区分大小写。

## 一次典型编辑

1. `hx 项目目录`，Space f 选文件；选择器隐藏点文件，但忽略文件规则被关闭，可能出现被 Git 忽略的普通文件。
2. r r 输入出现的标签快速定位词，按 v 扩展选区，c 后输入替换内容；Escape 或 j k 返回。
3. ] e 找诊断，Space a 看修复；g d 看定义。这些能力取决于对应语言服务已启动。
4. q q 统一格式，`:w` 保存。全局自动保存关闭；保存格式化是否启用还继承语言默认，只有 TOML 明确关闭 auto-format，不能理解为“所有语言都不在保存时格式化”。

如果 j 不能立即输入，先确认是否在等待 j k 序列。终端拦截 Alt+x 时可直接用 Escape。剪贴板异常先检查 pbcopy/pbpaste 与终端环境；SSH 中不保证等同本机剪贴板。语言问题先运行 `hx --health 语言名`，再看 `:log-open`，不要通过反复覆盖配置隐藏实际错误。
