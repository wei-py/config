界面三栏比例1:4:3，默认显示隐藏文件，目录优先、扩展名排序，行信息显示创建时间。进入后先按 `~` 看中文帮助。多键写作 `g e` 表示先 g 再 e。

## 让退出后 Shell 进入选中的目录

子进程不能直接改变父 Shell 当前目录。在自己的 zsh/bash 配置加入函数（安装脚本不会自动写）：
```sh
y() {
  local tmp cwd
  tmp=$(mktemp -t yazi-cwd.XXXXXX) || return
  yazi "$@" --cwd-file="$tmp"
  cwd=$(cat "$tmp")
  if [ -n "$cwd" ] && [ "$cwd" != "$PWD" ]; then
    builtin cd -- "$cwd"
  fi
  rm -f -- "$tmp"
}
```

从 `y` 启动后，q 或 g e 可通过 cwd 文件把位置交回 Shell；Q 明确不更新。普通 `yazi` 启动再退出，不会改变原 Shell。g e 只对目录有效。

## 三步整理流程

用 s 找文件，Space 多选，y 复制或 x 剪切，到目标目录 p p；进入文档用 Enter 打开 Helix；处理完用 [ 给常用目录加书签。删除先选 d，确定不需恢复才考虑 D。Mac 上不要用 `M m` 等 GVFS 键解决 SMB/MTP；先用系统或专用工具挂载，再浏览挂载点。
