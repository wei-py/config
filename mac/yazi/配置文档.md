# Yazi 配置：保留插件，分清平台与外部依赖

| 文件 | 职责 |
| --- | --- |
| yazi.toml | 三栏布局、排序、opener、预览规则、1GiB 图片分配上限 |
| keymap.toml | 各模式完整中文键位；mgr 用 keymap 覆盖默认键位 |
| init.lua | full-border、starship、simple-status、yamb、duckdb 初始化；Linux 才启动 GVFS |
| package.toml | 插件/主题来源与 revision/hash；不是本机自定义文件的完整备份清单 |
| plugins/ | 已随包携带实际 Lua 和资源，包括自定义 cd-hover-quit |
| flavors/ | Dracula 与 Catppuccin Mocha 主题资源 |
| bookmark | 新电脑空书签库；之后会写入个人路径 |

## 外部命令

| 功能 | 依赖 |
| --- | --- |
| 文本编辑 | hx；修改 yazi.toml 的 opener.edit 可换编辑器 |
| 顶部提示符 | starship；不需要在 Shell 启用其 init 也可由插件调用 |
| 媒体预览 | mediainfo、ffmpeg；终端图像协议和字体也影响效果 |
| DOCX / Typst | pandoc / typst |
| 表格/数据库预览 | duckdb；XLSX 等类型可能按插件请求下载安装扩展 |
| 压缩 / 内置解压 | ouch / 7z（Homebrew sevenzip） |
| 搜索/跳转 | fd、rg、fzf、zoxide |
| 常见 PDF/SVG/图像等预览 | pdftoppm（poppler）、resvg、ImageMagick；按使用文件类型安装 |
| Mac 磁盘挂载 | 系统 diskutil，插件支持 macOS |
| Linux GVFS | GLib/GVFS/D-Bus，可选 keyring/pass；Mac 不启用 |

plugins/里有 git 插件与锁定注册项，但 init.lua 没有 require git:setup，不能声称 Git 状态显示已启用。开启新功能前先阅读对应插件随附 README。已附插件不等于已附所有外部依赖或网络扩展。

## 改键、改主题、改书签

完整覆盖式 keymap 不会自动继承新版默认键。升级 Yazi 要比对新动作和参数；改键后重开，帮助以实际配置为准。`g v` 保留原 `~/Videos`，Mac 常见 Movies 目录需按自己情况改。

当前 theme.toml 保留大量显式配色，不是“只引用 flavor”的配置。若要纯用 Dracula/Catppuccin，先备份 theme.toml，再将其完整替换为：
```toml
[flavor]
dark = "dracula"
light = "dracula"
```
换 Catppuccin 则两项都改为 `catppuccin-mocha`。只在原文件末尾加 flavor 会被显式颜色覆盖，不等于完整换肤。

init.lua 的书签和 GVFS 保存路径按 XDG_CONFIG_HOME/HOME 计算，不含原用户名。新电脑书签为空；日后备份时 bookmark 与 gvfs.private 可能包含私有路径/远端地址，不应未经审查提交。

## 迁移差异记录

1. 保留真实键位、Helix opener、g e 自定义插件和完整本地插件/主题。
2. 文件保存路径由硬编码用户目录改为环境变量计算；GVFS 初始化仅 Linux 执行。
3. 删除旧 U 上游强制更新入口和对应脚本，避免覆盖本包；删除旧 `/run/user/1000/gvfs` 与 `USER_NAME` 预览规则，Mac 不依赖这些路径。
4. 空书签随包提供；不附缓存、Git 元数据、会话、挂载凭据和个人配置备份。第三方 LICENSE 随各插件和主题保留。

## 验证与更新

```sh
yazi --version
yazi --debug
```
再实际进入 Yazi 检查边框/提示符，打开文本、建立两个标签测试 -/=，保存书签后退出重开确认持久化；在临时目录测试复制/重命名，避免拿真实数据试删除。

`ya pkg install` 只能按清单管理上游依赖，不能恢复自定义 cd-hover-quit 或本地补丁；整目录才是本包的完整来源。更新某插件前备份、检查 API 与 revision，勿盲目批量升级。图标方框先查 Nerd Font；顶部报错查 starship；预览失败按表检查外部命令和插件提示；g e 后 Shell 没变目录先确认是否通过 y 函数启动。
