# Hammerspoon 配置：入口、模态、动作分层

配置目录固定为 `$HOME/.hammerspoon`。只需要入口和 `lib/` 五个 Lua 模块，无 Spoons、第三方 Lua 包、EPOMAKER 键盘固件依赖。新机器仍需要 macOS、Hammerspoon 与本机系统授权。

## 模块职责与加载顺序

| 文件 | 职责 |
| --- | --- |
| `init.lua` | 加载 hs.ipc，清除五个模块的 require 缓存，依次初始化 Caps 与绑定，设置退出清理 |
| `lib/notify.lua` | success/warn/error 三类系统浮层提示 |
| `lib/capslock.lua` | hidutil 将 Caps 映射 F13；按下/松开控制模态；监听短按 Shift |
| `lib/utils.lua` | 发送组合键；统一绑定按下、松开和长按重复回调 |
| `lib/window.lua` | 可用屏幕区域最大化、左右半屏、原生全屏、Space 循环 |
| `lib/bindings.lua` | 主键位表、应用启动、音量 HUD、Herdr 异步 CLI、全局 Cmd+1/2 |

入口的成功提示出现在后续模块初始化前，不能只凭 `Hyper Key Config Loaded` 断言全部加载成功。Console 的实际错误及按键动作才是依据。

## 修改入口

- **增加 Caps 动作**：在 `bindings.setup` 内按既有方式调用 `utils.bindModalKey(modal, "键", callback)`；第四参数 true 才启用重复。先核对键位是否已占用。
- **改应用**：更换 `hs.application.launchOrFocus("应用名")`；有固定 bundle ID 的软件优先用 `launchOrFocusByBundleID`。不存在的可选应用不会由脚本自动安装。
- **改 Herdr 上下文**：Caps+N 查找精确小写 `me` Workspace 和名称为 `1` 的 Tab。修改 `item.name` 两处判断和对应提示；保留按 ID 选择与重名检查。它不创建会话、不保存固定 ID。
- **取消全局抢键**：删除或更换 `bindings.lua` 末尾两条 `hs.hotkey.bind({"cmd"}, "1"/"2", ...)`。它们在 Caps 模态外同样有效。
- **关闭短 Shift 切输入法**：在 `capslock.lua` 停用 flagsChanged watcher 的建立/启动；同时保留清理逻辑与其他 Caps 初始化。现有实现不检测期间是否输入过字母，存在误触，详见操作文档。
- **窗口布局**：修改 `window.changeLayout` 中比例。最大化不是原生全屏；退出原生全屏后只等待50毫秒，动画尚未完成时可能需重试。
- **音量外观**：改 bindings.lua 的 HUD 尺寸/颜色。画布和计时器复用，最后一次操作1秒后隐藏；当前逻辑不提供静音切换。

菜单选择 Reload Config 后观察 Console；若涉及全局映射清理，先正常退出再重新打开通常更容易确认状态。不要在另一份配置中重复注册同一全局快捷键。

## 系统权限与冲突

辅助功能授权允许窗口与按键控制；事件监听受系统版本、输入监控和 Secure Input 影响。权限数据库不能复制到另一台 Mac，也不应尝试绕过授权。输入法动作发送 Ctrl+Space，要在新机系统键盘快捷键中自行核对。

`hidutil` 设置的是整个 UserKeyMapping 数组，而不是在原数组中追加 Caps 条目；退出清理又清空整个数组。运行前检查 Karabiner、系统修饰键设置和键盘固件，避免同时管理 Caps。单击 Caps 不会发送 Escape、切输入法或大小写锁定，按下即进模态、松开即出。

此配置加载 `hs.ipc` 供本地控制；不应把 IPC 或 Console 权限交给不可信进程。快捷键可执行应用和 Herdr CLI；这里只迁移已存在的代码，没有添加网络上传、按键日志或账户配置。

## 安装、恢复与迁移差异

`sh ./install.sh` 只移动旧配置到唯一备份，然后复制 config/，不自动启动、不修改 Shell、不设登录项、不申请权限。先退出 Hammerspoon再安装；脚本结束后打开应用并重新授权。恢复方法见 README，使用备份目录整体恢复，避免新旧模块混装。

这次保留原入口与五个模块的真实行为，没有用通用 Hyper 模板替换现有 Caps 方案。未带 `EPOMAKER_Hack59_usb.JSON`，因为 Lua 未读取它；未带 Spoons，因为入口没有引用。没有硬编码个人目录、终端会话或登录凭据需要迁移。外部应用名称、Herdr 的 `me/1` 是保留的个人工作流约定，需要在新机建立或自行调整。

## 新机验收

1. 打开 Console，确认 require/setup 无错误，单纯语法检查不能证明系统授权有效。
2. 在临时文本中试 Caps+H/L 和 D；测试窗口再试左右半屏。
3. 检查短 Shift 与系统输入法快捷键是否符合预期，有误触就先停用该 watcher。
4. 在可软件调音量的设备上测试 Caps+=/-；数字音频输出不保证支持。
5. 安装 Herdr 并建立唯一 `me/1` 后测试 Caps+N，再测试全局 Cmd+1/2 是否可接受；不接受则先改键。
6. 正常退出，确认原 Caps 行为是否恢复，注意它不会恢复启动前由别的软件设置的 UserKeyMapping。
